# Outils de maintenance

Ce dossier contient les utilitaires destinés aux mainteneurs. `capture-docs.js` produit les captures du README à partir de données fictives avec `npm run docs:screenshots`. `render-readme-demo.js` assemble ces captures en deux démonstrations animées avec `npm run docs:demo` ; cette commande nécessite FFmpeg.

Ces outils ne sont pas intégrés aux applications distribuées.
