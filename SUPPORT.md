# Assistance

Avant d’ouvrir une demande, consultez le [guide utilisateur](docs/USER-GUIDE.md), la [compatibilité](docs/COMPATIBILITY.md) et le [dépannage](docs/TROUBLESHOOTING.md).

## Signaler un bug

Utilisez une issue GitHub avec :

- la version de CTRL KANB ;
- le système et son architecture ;
- les versions de Codex ou Claude Code concernées ;
- les étapes minimales pour reproduire le problème ;
- le résultat attendu et le résultat observé ;
- une capture utilisant des projets et contenus fictifs si elle est nécessaire.

Supprimez ou remplacez systématiquement les noms réels, chemins utilisateur, consignes, réponses, identifiants de conversation, journaux, emails et informations de compte. Ne joignez jamais `board.json`, `events.jsonl`, un export réel, un dossier de configuration d’agent, un jeton ou une clé.

## Demander une évolution

Décrivez le besoin utilisateur, le parcours actuel et le résultat souhaité. Une proposition qui modifie les workflows **Classique** ou **Routines**, le stockage, les permissions ou les garanties sur les dossiers doit expliquer les conséquences sur les données existantes.

## Problème de sécurité

N’ouvrez pas d’issue publique. Suivez [SECURITY.md](SECURITY.md) et utilisez le signalement privé GitHub.

## Services externes

CTRL KANB est indépendant d’OpenAI et d’Anthropic. Les problèmes de compte, facturation, quota ou disponibilité d’un service doivent être traités avec le fournisseur concerné. Le projet ne garantit aucun délai de support.
