# Third-party product names / Noms de produits tiers

## English

CTRL KANB is an independent project. It is not affiliated with, endorsed by, or sponsored by OpenAI or Anthropic.

“Codex”, “Claude”, and “Claude Code CLI” are used only to identify compatible local tools and the agent selected by the user. Technical references to “Codex CLI”, “Codex App Server”, and “Claude Code CLI” describe executables installed and authenticated by the user.

CTRL KANB does not provide an account, subscription, quota, API key, or hosted access to OpenAI or Anthropic. It launches tools installed on the user’s computer and relays their local output. Each tool remains subject to its own terms of use.

When it initializes Codex App Server, CTRL KANB declares its own client identity as `ctrl-kanb` and its product title as `CTRL KANB`.

No OpenAI or Anthropic logo, symbol, or visual asset is bundled. The code and terminal pictograms shown in the interface are original, generic CTRL KANB interface icons.

OpenAI and Codex are trademarks of OpenAI. Anthropic, Claude, and Claude Code are trademarks of Anthropic PBC. Those marks are not covered by CTRL KANB’s Apache-2.0 license. Modified distributions must not present CTRL KANB as an official, affiliated, approved, or sponsored product of either company.

- [Codex App Server](https://github.com/openai/codex/tree/main/codex-rs/app-server)
- [Run Claude Code programmatically](https://code.claude.com/docs/en/headless)
